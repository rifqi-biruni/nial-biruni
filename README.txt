BLADEPRO WEBSITE - 7 HALAMAN

STRUKTUR:
- index.html       : Home
- about.html       : About Us (profil, visi, misi)
- services.html    : daftar layanan dan perlengkapan barber
- haircut.html     : detail Haircut, manfaat, dan tahapan pengerjaan
- fade.html        : detail Fade & Taper, manfaat, dan tahapan pengerjaan
- styling.html     : detail Hair Styling dan Beard Grooming
- contact.html     : informasi kontak dan formulir pesan
- css/style.css    : seluruh desain, responsif, running text, animasi
- js/script.js     : menu mobile, animasi reveal, tahun otomatis, form email

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder bladepro_7_pages di Visual Studio Code.
3. Klik kanan index.html lalu pilih Open with Live Server (jika ekstensi Live Server tersedia).
4. Gunakan menu navigasi atau kartu layanan untuk berpindah halaman.

SEBELUM PUBLISH:
- Ganti email hello@bladepro.com, nomor telepon, dan alamat contoh dengan data resmi.
- Pastikan daftar layanan dan produk sesuai dengan layanan/produk yang benar-benar tersedia.
- Tambahkan foto asli barbershop, tim, atau produk jika sudah ada.
- Form kontak menggunakan mailto, sehingga membuka aplikasi email. Untuk menerima pesan langsung dibutuhkan backend atau layanan form.

Catatan: Font Google Fonts membutuhkan koneksi internet. Jika offline, font cadangan akan digunakan.
